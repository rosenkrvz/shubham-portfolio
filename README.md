---

## Visual Design & Engineering Philosophy

- **Inverted Bone Column**: Deep void ink (`#0B0B0C`) with tactile bone parchment (`#E9E7E1` / `#DFDCD3`) and sharp dark typography (`#0A0A0B`).
- **Signature Accent**: Ultramarine electric blue (`#3E2CF0` / `#5344F5`) for action calls and interactive focus states.
- **Typography Stack**:
  - Primary UI: *Plus Jakarta Sans*
  - Display & Headings: *Space Grotesk*
  - Code & Telemetry: *JetBrains Mono*
- **1-Bit Spatial Dithering**: Custom CSS halftone filters and canvas Bayer 4x4 matrix processing.
- **Fluid Micro-Interactions**: Interactive particle wave displacement via `FluidCanvas.jsx`.

## Tech Stack

- **Framework**: [React 19](https://react.dev/) with [Vite 6](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) with curated design tokens
- **Animations & Micro-interactions**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) & Custom SVG Social Icons
- **Typography**: Space Grotesk, Plus Jakarta Sans, JetBrains Mono
- **Deployment**: [Vercel](https://vercel.com/) (Edge Global CDN)

---

## Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start Vite dev server with instant HMR (http://localhost:5173)
npm run dev

# 3. Build production bundle (into dist/)
npm run build

# 4. Preview production build locally (http://localhost:4173)
npm run preview
```
